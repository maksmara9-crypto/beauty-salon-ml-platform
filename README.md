# Сұлулық салонын басқарудың интеллектуалды цифрлық платформасы

Дипломдық жоба сұлулық салонындағы қызметтерді, мамандардың кестесін және клиент жазбаларын бір жүйеде басқаруға арналған. Клиент бос уақытты іздеп, қызметке онлайн жазылады; машиналық оқыту сервисі оның қалауы мен алдыңғы келулерін ескеріп, сәйкес маман мен уақытты ұсынады. Салон қызметкерлері жазбаларды және жұмыс кестесін бақылайды.

## Мақсаты

Клиенттің қызметке жазылуын жеңілдетіп, салонның кестесі мен жазбаларын дәл әрі тиімді басқару.

## Пайдаланушылар

- **Клиент** - қызметтерді қарайды, ұсыныс алады және жазылады.
- **Маман** - өз кестесі мен алдағы жазбаларды қарайды, қызметтің орындалу күйін жаңартады.
- **Әкімші** - қызметтерді, мамандарды, кестелерді және барлық жазбаларды басқарады.

## Талаптар

1. Клиент тіркеліп, жүйеге кіре алады.
2. Клиент қызметтердің сипаттамасын, бағасын және ұзақтығын қарай алады.
3. Клиент қызмет пен қалауын енгізгенде, жүйе бос уақыттарды алып, ML сервисі арқылы маман мен уақыт нұсқаларын реттеп көрсетеді.
4. Клиент ұсынылған маман мен уақытты таңдап, жазылуға сұрау жібере алады; жүйе уақыттың бос екенін қайта тексеріп, жазбаны атомарлы сақтайды.
5. Таңдалған уақыт бос болмаса, жүйе клиентке балама бос уақыттарды көрсетеді және жаңа уақыт таңдауды ұсынады.
6. Жазылу сәтті аяқталса, жүйе клиентке жазбаның растауын жібереді.
7. Маман өз кестесі мен алдағы клиент жазбаларын қарап, орындалған қызметтің күйін жаңарта алады.
8. Әкімші қызметтерді, бағаларды, мамандарды және олардың жұмыс уақытын өзгерте алады.

## Құжаттама

Екі диаграмма да **«Клиентті қызметке жазу»** сценарийін сипаттайды. Жүйе алдымен бос уақыттарды және клиент тарихын алады, ML сервисі нұсқаларды реттейді. Клиент уақытты таңдаған соң жүйе оны қайта тексереді: бос болса жазбаны сақтап, растау жібереді; бос болмаса балама уақыттарды ұсынады.
